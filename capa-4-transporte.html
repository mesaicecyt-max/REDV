1.9 Capa 4: Transporte

🚚 Capa 4: Capa de Transporte (Transport Layer)

La Capa de Transporte es el puente entre la red y las aplicaciones. Su misión es garantizar que los datos lleguen desde una aplicación en un host origen hasta la aplicación correcta en el host destino, de forma ordenada, eficiente y, si es necesario, confiable.

🔍 1. Concepto Fundamental

Funciones clave de la Capa 4:

  • 🔢 Multiplexación/Demultiplexación: Maneja múltiples conversaciones simultáneas.
  • ✅ Entrega confiable (TCP): Asegura que los datos lleguen completos y en orden.
  • 📊 Control de flujo: Evita que el receptor se sature.
  • 🚦 Control de congestión (TCP): Regula el tráfico para evitar sobrecarga en la red.

📦 2. Temas Clave

A. Puertos y Sockets

  • Puerto: Número de 16 bits (0–65535) que identifica una aplicación.
  • Socket: IP + Puerto (ej. 192.168.1.100:52000 ).
  • Puertos conocidos: 80/TCP : HTTP 443/TCP : HTTPS 53/UDP : DNS 25/TCP : SMTP

Puertos conocidos:

  • 80/TCP : HTTP
  • 443/TCP : HTTPS
  • 53/UDP : DNS
  • 25/TCP : SMTP

B. TCP – El Protocolo Confiable

  • 🔗 Orientado a conexión: Usa el three-way handshake (SYN, SYN-ACK, ACK).
  • 📦 Confiable: Números de secuencia y ACKs. Retransmisión si hay pérdida. Checksum para verificar integridad.

📦 Confiable:

  • Números de secuencia y ACKs.
  • Retransmisión si hay pérdida.
  • Checksum para verificar integridad.
  • 📉 Control de flujo: Ventana deslizante.

🌐 Control de congestión: Ajusta velocidad según condiciones de red.

  • 🧰 Usos típicos: HTTP/S, SMTP, FTP, SSH.

C. UDP – El Protocolo Rápido

  • 🚫 No orientado a conexión: Sin handshake.
  • ❌ No confiable: Sin ACKs ni retransmisión.
  • ⚡ Sin control de flujo ni congestión.

Sin control de flujo ni congestión.

  • 🧮 Cabecera mínima: Solo 8 bytes.
  • 🎮 Usos típicos: VoIP, streaming, juegos online, DNS, multicast.

🛠️ Herramientas de Diagnóstico

  • netstat , Wireshark , tcpdump muestran conexiones activas, puertos y estados TCP.

✅ Conclusión

La Capa de Transporte es el gestor de tráfico entre aplicaciones . Define cómo se comunican los procesos, qué protocolo usar (TCP o UDP), y cómo manejar la velocidad, confiabilidad y eficiencia. Sin ella, las aplicaciones no podrían intercambiar datos de forma ordenada ni segura.
