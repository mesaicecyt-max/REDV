1.7 Capa 3: Red

🌐 Capa 3: Capa de Red (Network Layer)

La Capa de Red es el corazón de la conectividad lógica entre redes. Mientras la Capa 2 se encarga de la comunicación dentro de una red local (LAN), la Capa 3 permite que los datos viajen entre redes distintas, incluso a través de continentes. Es la capa que hace posible Internet.

Piensa en ella como el sistema postal internacional: decide cómo y por dónde debe viajar cada paquete de datos para llegar a su destino.

🔍 1. Concepto Fundamental

La Capa 3 se encarga de:

  • 🧭 Direccionamiento lógico: Asigna direcciones IP independientes del hardware.
  • 🚦 Enrutamiento: Determina el mejor camino para llegar al destino.
  • 🔀 Conmutación (Forwarding): Mueve paquetes entre interfaces de router.
  • ✂️ Fragmentación: Divide paquetes grandes para adaptarse a redes con diferentes tamaños de trama (MTU).

📦 2. Temas Clave

A. Protocolo IP – El Rey de la Capa 3

IPv4:

  • Dirección de 32 bits (ej. 192.168.1.1 ).
  • Usa máscaras de subred (ej. /24 ) para dividir redes.
  • Permite fragmentación por parte de los routers.

IPv6:

  • Dirección de 128 bits (ej. 2001:db8::1 ).
  • Espacio de direcciones masivo.
  • Seguridad integrada (IPsec).
  • Fragmentación solo desde el host origen.

B. Algoritmos de Enrutamiento

Protocolos IGP (Interior Gateway Protocols):

  • 🧭 RIP: Simple, limitado a 15 saltos.

🧠 OSPF: Calcula rutas óptimas usando el algoritmo de Dijkstra. Ideal para redes grandes.

Calcula rutas óptimas usando el algoritmo de Dijkstra. Ideal para redes grandes.

Protocolos EGP (Exterior Gateway Protocols):

🌐 BGP: El protocolo que hace funcionar Internet. Basado en políticas y acuerdos entre ISPs.

C. Dispositivos Clave

  • Router: Interconecta redes diferentes. Usa direcciones IP para tomar decisiones. Marca el límite de un dominio de broadcast.

✅ Conclusión

La Capa 3 es el cerebro del routing y la escalabilidad de las redes. Gracias al direccionamiento lógico y a los protocolos de enrutamiento, permite que millones de redes se conecten en una sola internetwork global. Sin ella, Internet no existiría tal como lo conocemos.
