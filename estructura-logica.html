4.1 Estructura Lógica

🔍 ¿Qué significa identificar la estructura lógica de un algoritmo?

Es reconocer cómo están organizadas las instrucciones dentro del algoritmo, según el tipo de operación que realizan. Existen tres estructuras básicas:

1. 🧱 Secuencia

  • Definición: Instrucciones que se ejecutan una tras otra, en orden.
  • Ejemplo: Encender la estufa Colocar el sartén Poner la tortilla Agregar queso

Ejemplo:

  • Encender la estufa
  • Colocar el sartén
  • Poner la tortilla
  • Agregar queso
  • Indicadores: No hay condiciones ni repeticiones. Todo se ejecuta una sola vez y en orden.

2. 🔀 Decisión (Condicional)

  • Definición: El algoritmo elige entre dos o más caminos según una condición.
  • Ejemplo: Si la tortilla está dorada, entonces voltearla. Si no hay queso, detener el proceso.
  • Si la tortilla está dorada, entonces voltearla.
  • Si no hay queso, detener el proceso.
  • Indicadores: Uso de palabras como “si… entonces…”, “en caso de…”, “de lo contrario…”

3. 🔁 Repetición (Bucle)

  • Definición: Una o más instrucciones se repiten mientras se cumple una condición.
  • Ejemplo: Repetir: frotar las manos hasta completar 20 segundos. Mientras el ciclo de lavado no termine, esperar.
  • Repetir: frotar las manos hasta completar 20 segundos.
  • Mientras el ciclo de lavado no termine, esperar.
  • Indicadores: Palabras como “mientras…”, “repetir hasta…”, “durante…”

🧠 ¿Cómo aplicarlo en clase?

Al analizar un algoritmo cotidiano, los estudiantes deben:

  • Subrayar las instrucciones que forman parte de una secuencia.
  • Encerrar en un recuadro las decisiones.
  • Marcar con un símbolo (por ejemplo 🔁) las repeticiones.

Esto les ayuda a visualizar cómo se construyen los programas reales y a desarrollar pensamiento computacional.
